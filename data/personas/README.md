# Generated persona cards

Click **Save persona card** or **Save individual engine JSON files** in Persona
Studio to write reviewed/generated cards here as `studio-<unique-id>.json`.

Generation alone previews cards in browser memory; click Save to persist them.
Each JSON is a single `sue-persona` v2 card. Engine execution is not included.
Parameter/source records are stored separately under `data/studio-configurations/`.

Actual persona JSON files are ignored by Git to avoid publishing participant data.
This README keeps the output directory visible in the repository.
